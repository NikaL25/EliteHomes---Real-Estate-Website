# 🏠 EliteHomes - Real Estate Website

A modern and responsive real estate website built with **HTML, CSS, and JavaScript**.

## ✨ Features

- 🏠 Modern responsive design
- 🏘️ Featured properties section
- 📱 Mobile navigation menu
- 📊 Animated statistics counters
- ✨ Scroll and fade-in animations
- ⌨️ Typing effect for the hero title
- 🖱️ Property card hover effects
- 📩 Contact form with validation
- ❤️ Property favorites using `localStorage`
- ⚖️ Property comparison functionality
- 🌊 Smooth scrolling
- 🎨 Parallax effect for the hero section

## 🛠️ Technologies

- **HTML5**
- **CSS3**
- **JavaScript**
- **Font Awesome**
- **Unsplash**
- **LocalStorage API**
- **Intersection Observer API**

## 🚀 How to Run

💻 Local

1. Download or clone the repository.
2. Open the project folder.
3. Open index.html in your browser.
4. No additional dependencies are required.
